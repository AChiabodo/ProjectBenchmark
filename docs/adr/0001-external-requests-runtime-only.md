# External requests are runtime-only; build-time dependencies are pinned

A runtime no benchmark may issue any network request: no external APIs, remote assets or services — every resource is local or generated by the code. Build-time dependency fetches are allowed only when pinned (lockfile, or tag plus hash), e.g. the raylib source tarball fetched by CMake FetchContent. Trade-off: we lose the realism of live pipelines and CDN-served assets, and we gain full offline reproducibility, a runnable deny-list check (`scripts/index.mjs --check`) and runs that cannot silently depend on the weather of the network.
